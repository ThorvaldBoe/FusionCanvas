# Add Architecture Deepening Review Retrospective

## Outcome

The Software Factory now has a manual, evidence-backed Architecture Deepening Review for identifying worthwhile opportunities to deepen shallow modules. The procedure is separate from ordinary audits, uses explicit deep-module vocabulary, records candidate trade-offs and test surfaces, and routes selected work through OpenSpec or the maintenance workflow.

## ADDED Requirements

### Requirement: Workspace settings provide access to artwork style management
FusionCanvas SHALL expose Manage artwork styles from Workspace settings for the active workspace and SHALL open the focused style-management surface in that workspace scope.

#### Scenario: User opens artwork style management from settings
- **WHEN** the user activates Manage artwork styles in Workspace settings
- **THEN** FusionCanvas opens the style-management surface for the active workspace
- **AND** does not create or select a different workspace

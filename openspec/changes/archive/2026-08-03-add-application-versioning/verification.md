## Validation Gates

- Focused tests: Pass — `ApplicationVersionDiagnosticsTests` (8 passed) and `SettingsAboutTests` (4 passed) plus `SettingsWindowTests.AboutSection_ShowsProductVersionAndCopyDiagnosticsButton` (1 passed).
- Solution build: Pass — 0 errors in Debug and Release; 204 pre-existing analyzer warnings remain unchanged.
- Solution test baseline: Pass — 873 passed, 0 failed across all four test projects (Domain 150, Application 250, Integration 122, App 351).
- Strict change validation: Pass — `openspec validate add-application-versioning --strict`.
- Changed-scope review: Pass — changes are limited to `version.json`, `Directory.Build.props`, the new `FusionCanvas.Application/Versioning/` and `FusionCanvas.App/Versioning/` files, the `SettingsSection.About` addition, `SettingsViewModel` version/diagnostics projection and copy command, the `SettingsWindow.axaml` About pane, `AppServicesFactory` production wiring, the new tests, and the `CONTRIBUTING.md` versioning section. No Domain, Integration, persistence schema, file format, plugin, AI, marketplace, or workflow behavior changed.

## Overall Result

All acceptance scenarios pass with deterministic evidence. The canonical version is derived from the repository, the application exposes it through an application-level service, the About section displays and copies version diagnostics, and the contributor documentation records the GitHub Actions checkout requirement and the release tag convention.
